# RAKON-OS (Hybrid Core v2.0)

## Estructura Operativa
1. **NÚCLEO TÉCNICO:** Lógica de sistemas (ALPHA) y arquitectura de datos (EPSILON) bajo supervisión del KERNEL.
2. **NÚCLEO CREATIVO:** Diseño visual (BETA), planificación estratégica (GAMMA) y protocolos de bienestar (DELTA).

## Directorios
- `/src` & `/data`: Desarrollo y Bases de Datos.
- `/ui` & `/management`: Interfaz y Estrategia.
- `/health`: Optimización del factor humano.
