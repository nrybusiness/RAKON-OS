# RAKON-OS | Sistema de Gestión Unificado (Arquitectura Híbrida)
**Arquitecto Líder:** Nicolás
**Socio Estratégico:** KERNEL

## Visión
RAKON-OS opera bajo un modelo híbrido. Utiliza GitHub como Single Source of Truth (SSOT) para la lógica, control de versiones y texto plano, y Google Drive para el almacenamiento exclusivo de activos visuales y multimedia pesados.

## War Room (Núcleos Operativos)
1. **ALPHA (Sistemas):** Lógica, automatización, bases de datos y repositorios de código (GitHub).
2. **BETA (Estética):** Dirección de arte, UI/UX, diseño audiovisual y gestión de medios (Drive).
3. **GAMMA (Estrategia):** Planificación, modelos de negocio y ejecución de proyectos.
4. **DELTA (Bienestar):** Monitoreo de carga cognitiva y optimización del entorno del Arquitecto.
5. **EPSILON (Datos):** Análisis, métricas y estructuración de información técnica.

## Entornos de Ejecución
- **GitHub (`RAKON_OS_REPO`):** Alberga `/00_SYSTEM`, `/01_LIBRARY/logic_snippets` y el código fuente en `/02_PROJECTS`.
- **Google Drive (`RAKON_OS_DRIVE`):** Alberga `/01_LIBRARY/creative_assets` y los recursos audiovisuales en `/02_PROJECTS`.
